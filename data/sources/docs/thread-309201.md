### post #1 — TheNelston — Jul 6, 2023 at 10:38 AM

Intro

This is a pretty straightforward suggestion, make it so guilds can create an in-game multi guild "alliance" chat that can be typed into using the /a command or something similar.

Details

Participating guilds can only be in one alliance chat group at one time to prevent clutter, and players can opt in/out of the chat if they don't want to see it

For an example in another game, look at Maplestory's alliance chat system- a direct port would be nice, but something approximate is ok too

This would allow for more community building between guilds that's currently very restricted to discord, and lets smaller guilds coordinate things much easier in game (e.g: raids/dungeon runs)

Potential Issues

One potential con could be that some guilds might just use this as an opportunity to make many subguilds and have them conglomerate into one mega guild, but the one alliance limitation should make it so guilds are forced to decide between making an alliance with subguilds, or making one with war partners/other guilds, thus reducing the prevalence of that issue
